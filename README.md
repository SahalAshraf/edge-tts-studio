# Google TTS Vercel Web App

A lightweight, serverless Text-to-Speech web application built with Python (`gTTS`), FastAPI/HTTP handler, and a responsive Tailwind CSS frontend, deployed on Vercel.

## Deployment Steps
1. Create a new repository on GitHub and upload these files (`api/`, `index.html`, `requirements.txt`, `vercel.json`, `README.md`).
2. Log in to [Vercel](https://vercel.com).
3. Click **Add New -> Project** and import your GitHub repository.
4. Leave build settings as default and click **Deploy**.
5. Open your generated Vercel URL on your phone or browser to use the app!
